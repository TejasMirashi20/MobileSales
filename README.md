# 📱 Mobile Sales Data Analysis Dashboard

## 📌 Project Overview
This project analyzes mobile phone sales data using Power BI to identify sales trends, product performance, and customer purchasing patterns.

## 🛠️ Tools & Technologies
- Power BI
- Power Query
- DAX
- Microsoft Excel

## 📊 Key Performance Indicators (KPIs)
- Total Sales
- Total Quantity Sold
- Total Transactions
- Average Sales

## 📈 Analysis
- Sales performance by mobile brand and model
- Monthly sales trends
- Customer purchasing behavior
- Payment method analysis
- Geographic sales performance


## 📁 Project Files
data — Raw mobile sales dataset
powerbi — Power BI dashboard screenshot 

## 🎯 Objective
To transform raw sales data into meaningful insights and support data-driven business decisions.
